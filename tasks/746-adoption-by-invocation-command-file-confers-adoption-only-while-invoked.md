- [#746] [P1][M] **Adoption-by-invocation — a command file confers adoption only while telemetry records real invocations, and it decays at 30 days** - ADR-119 (Accepted 2026-09-13), from intake #94 and operator ratification 2026-09-13 item 1. **This row exists because the decision requires a build**, and ADR-111 guard (i) refuses an accepted decision that schedules nothing; `decision_coverage` ([#692], A9-1) is the organ that would refuse it at commit tier. · **The defect ADR-119 answers.** The `[#664]` census reads five wiring surfaces and `.claude/commands/*.md` is none of them, so every operator-invoked organ reads as an orphan by construction — 21 of 37 disposition rows on the 2026-09-13 census (`docs/audits/2026-09-13-census-x-664-delete-list.md` §4.3, §4.4, §4.5), a clear majority, growing by one every time a lane writes an operator-invoked organ. It grew by one DURING that census, when the lane wrote `propose_row_closures.py`. · **Why the cheap repair is the dangerous one.** Simply admitting the surface asserts adoption of 21 modules on the evidence that somebody wrote down a way to call them. A module named by a command nobody runs is exactly as dead as a module named by nothing, and the register would have been taught to say otherwise — the same shape as `desired_state_loader.py`, deleted on a static SAFE verdict, suite RED, restored whole. The operator's framing is the binding one: what he is buying is **not a smaller register** but the guarantee that Claude uses the organs it builds. · **Scope: three parts.** (1) `.claude/commands/*.md` enters the census's wiring-surface list as the ONE conditional surface — the other five confer *triggered* unconditionally because an event fires them. (2) A rolling 30-day invocation window per organ, read off **AX9-5's counter** (organ calls per session) — one counter, not a second telemetry path. (3) A decay rule: an organ whose window closes with no recorded invocation RETURNS to the register, reported as a return with the date of its last recorded invocation, not as a new finding. · **The register must keep two states distinct** — *nothing can invoke this* (no surface names it) and *nothing has invoked this lately* (a command names it, the counter is cold). They have different repairs and the census must not collapse them. · **Out of scope, explicitly.** Skills — `[#664]`'s anti-pattern list already rules that repair (*a skill's mandate becomes a HOOK, never a graph row*). And this row does NOT authorise adding a hook to any module to lower a count: for `merge_receipt`, `actions_verdict` and `review_packet` a hook is wrong on the merits (a stopwatch has nothing to gate; a merge SHA does not exist at commit time), and `lane-x-675-instrument-fixes` is forbidden from doing so by its own contract. · **The hard part is the telemetry, and it is not free.** Per-organ invocation with a timestamp must persist ACROSS sessions — a 30-day window cannot be answered from one transcript. Where it lives, and whether it survives a worktree teardown, is intake #94's open question, sharpened by the nine husk directories batch X4 found in `.claude/worktrees/` holding per-worktree state nothing reaped. · implements: ADR-119, intake-94 · Done when: `.claude/commands/*.md` is read as a wiring surface by the `[#664]` census AND an organ it names reads as adopted only while the rolling 30-day invocation window is non-empty; **a RED-first witness** per ADR-108 §B — an organ named by a command file with NO recorded invocation inside the window reads UNTRIGGERED, and that test FAILS before the decay rule exists; the adopted-by-invocation tier names its evidence per organ (last invocation, count in window) rather than reporting a bare adopted/not; **at least one observed RETURN** to the register on the 30-day decay, with its last-invocation date, is recorded — a decay rule that has never fired is an untested branch, not a healthy one; and the reading is taken off AX9-5's counter rather than a second instrument · **The flip condition is part of the contract, per ADR-119 §6:** if over two consecutive 30-day windows organs marked adopted-by-command show zero recorded invocations AND do not return to the register, the admission is laundering orphans and reverts to alternative A (command files are not a wiring surface); if attribution cannot be obtained without hand-instrumenting every call site, fall back to alternative D (a declared on-demand tier, honest and cheap).
