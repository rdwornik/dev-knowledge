- [#510] [P2][M] **Scope the R-1 exemption to the lanes its manifest enumerates — it is self-grantable by branch naming today** — `batch_manifest.exempt()` keys condition 1 on the merged branch's SHAPE alone (`LANE_BRANCH_RE = ^worktree-lane-[a-z0-9]+…`, read from the merge subject), not on the lane roster the open manifest declares. So **any** `worktree-lane-*` merge is exempt from `check_journal_spine_anchor` while a batch is open, and the exemption is one `git branch -m` away for a lane or an integrator. **This is not a hypothetical: batch 2 is the live demonstration** — renaming lane-1's auto-generated branch to `worktree-lane-a-490-parity-manifest` before merge is precisely the act that granted it the exemption, done in the open and recorded (packet §2 "F2 carried forward"). `batch_manifest.py`'s own HONEST LIMITS #2 declares the hole and says tightening it "is a separate decision, not a silent one" — which is why this is a row and not an edit. **Assessed for S-mechanical fix in the 2026-08-07 consolidation arc and rejected as M**, for three reasons that are the design work: (i) the manifest carries no machine-readable lane roster (frontmatter is `batch`/`status`/`closed_by`; the roster is prose), so this needs a schema addition; (ii) `docs/audits/` is immutable, so no existing manifest can be retrofitted and the change is prospective-only, which forces a back-compat posture — a manifest with no lane list exempts all lane merges (today's behaviour) or none (fail-closed), and that is a ruling; (iii) it ripples into PLAYBOOK Ch8's manifest description, the manifest template, and ADR-110's amendment text. **Blast radius is bounded and stays bounded:** the push leg never consulted the manifest, so nothing ships unanchored either way — pinned structurally by `test_the_pre_push_organ_does_not_consult_the_manifest_at_all` (AST, non-import) and behaviourally since 2026-08-07 by `test_t5d_the_r1_exemption_does_not_reach_the_pre_push_refusal`. · Done when: the exemption resolves against a lane roster the open manifest declares, the no-roster posture is operator-ruled and encoded, a test proves a lane branch OUTSIDE the roster is not exempt mid-batch, and Ch8 + the manifest template carry the field · refs `scripts/batch_manifest.py` (HONEST LIMITS #2, `LANE_BRANCH_RE`, `is_lane_merge`), `tests/test_batch_manifest.py`, `docs/audits/2026-08-07-technical-batch-2-packet.md` §2, ADR-110 amendment 2026-08-07, [#505] · kill-candidates: none — [#508] owns the lane-prefix enum's cardinality coupling, a different organ and a different defect;
