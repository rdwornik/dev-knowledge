- [#752] [P1][M] **A contract's declared model and mode reach no flag the background launcher honours, and nothing reads what a lane actually ran** - Reserved at the batch Y freeze (`docs/audits/2026-09-14-technical-batch-y-manifest.md`, slot 5) and frozen at `docs/audits/2026-09-14-technical-batch-y-launch-contracts/LANE-y-752-declared-model-runs.md`. **Two halves of one hole: a declaration nothing resolves, and an order nothing verifies.** · **(1) THE WITNESSED NO-OP, and every surface that could be read agreed with it.** `lane-x-689-conductor-e-proof` froze `| opusplan | execute | high |` under `**Shape:** local`; the operator ruled that tier onto the routing row AND onto the dispatch line so the lane could not re-decide it; `gen_lane_contract.MODEL_ENUM` was widened RED-first to admit it (batch X3 finding 1); `dispatch -DryRun` printed it; and `claude --print --model opusplan` resolves normally where a bogus id returns `[claude-code:unrecognized_model]`. The lane then ran **84 of 84 assistant messages on `claude-sonnet-5`, zero Opus**, while sibling lanes in the same fire returned exactly as ordered - so the instrument discriminates rather than reporting one answer. `opusplan` is a SPLIT tier (Opus while the session is in plan mode, Sonnet after) and every dispatch constant puts a lane on `--permission-mode bypassPermissions`, **which never enters plan mode**; no plan phase means no Opus phase. The consequence is stated in the batch X3 manifest's own words: every routing decision in that window was **advisory**. **Firing it literally does not honour the order either** - it yields Sonnet, which no contract names - so there is no faithful-literal option and passing the flag through is itself a deviation. · **(2) THE EXISTING GATES CANNOT CATCH IT, and that is a property of what they ask.** `check_contract` asserts the routing row and the dispatch line AGREE, and `MODEL_ENUM` admits `opusplan` because the CLI resolves it. Both were true here. **Agreement between two surfaces that are wrong about the same thing is not a check**: the missing question was never "do these two strings match" but "can the launcher this SHAPE uses actually HONOUR this value". · **(3) THE MODE COLUMN IS THE SAME DEFECT ONE COLUMN OVER, and it was never even visible.** `MODE_ENUM` has carried `plan` since it was written and `check_contract` validates the declared value against it - and **nothing anywhere resolves the column into a launcher argument**. A contract declaring `| opus | plan | high |` under `**Shape:** local` dispatches byte-identically to one declaring `execute`. A declared field no code reads is a decision the tree records and does not make. · **(4) THE RAN MODEL IS READABLE AND WAS NEVER READ.** The dispatch line records what was ASKED; only the lane's own transcript (`~/.claude/projects/<encoded worktree path>/*.jsonl`, `message.model` across assistant messages) records what RAN, and the method was validated against two completed wave-2 lanes before batch X3 relied on it. A merge receipt records the merge SHA, the suite's verdict STATE, the baseline it was attributed against and per-step minutes, and **not one field names the model the work was done at** - so a receipt timing an arc run at a tier nobody ordered is indistinguishable from one timing the arc that was ordered, and it feeds a median printed as the cost of that order. · **What must NOT be done, ruled out by name:** admitting `opusplan` on a `--bg` line with a warning instead of a refusal (there is no faithful-literal option to warn about); adding any flag that TYPES a ran-model onto a receipt (the ORDER is an input and is declared, the RAN model is READ - `[#744]`'s false pass reached by the cheapest route of all); refusing `opusplan` for an ATTENDED seat, which can enter plan mode and which AX22-3 routes the integrator to - same word, two populations; or refusing every pre-existing ledger row to arm the new field, which is `Verdict.ok`'s trap with a new field in it. · Done when: a contract's declared `| Model | Mode | Effort |` row resolves, under its declared `**Shape:**`, into the flags that shape's launcher HONOURS, with every dispatch constant emitted by name and none defaulted; `opusplan` is REFUSED on a background shape with its measurement in the refusal and PERMITTED on an attended one; a mode whose `--permission-mode` a `--bg` lane cannot run is REFUSED rather than silently dispatched as `execute`; a `--bg` dispatch line that DROPS `--model`, `--effort` or `--permission-mode` is refused (section V's own measured defect - roughly thirty consecutive seats launched lanes at a tier nobody chose); the ran-model is read off the lane's OWN transcript with an absent session store reported as a GAP and never as agreement (**Z-G4**), and a SPLIT tier reported as UNVERIFIABLE rather than as its implement half; a receipt whose ran-model differs from its ordered-model is INCOMPLETE with both named in the refusal and is EXCLUDED from the median; a receipt carrying NEITHER keeps the predicate it already had; there is **no flag anywhere** that can type a ran-model onto a receipt and a test asserts its absence;
