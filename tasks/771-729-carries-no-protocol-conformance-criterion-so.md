- [#771] [P2][S] **`[#729]` carries no protocol-conformance criterion, so a server can satisfy it completely and not be an MCP server** -- `[#729]`'s Done-when tests exactly one property, *"proven by a test that the server's output matches the script's for the same input"*, plus reachability from CC and one non-Claude provider and the no-hand-edit property when a query is added. Output equality against `graph_queries.py` is the right test for *"no second implementation of the graph"* and is silent about the protocol the server claims to speak. · **Two verified M04 items are the cheapest demonstration, and neither is visible to an output-equality test.** Tool annotations: *"Możemy też dodawać pewne podpowiedzi dotyczące charakteru danego narzędzia, tak jak np. readOnlyHint, który mówi, że to narzędzie nie ma żadnych skutków ubocznych, albo destructiveHint, że to narzędzie może usuwać dane"* (`AJ_M04_transkrypcje.md:159-162`) -- and the text fallback beside structured output: *"nawet jeżeli wysyłacie dane w tym takim nowoczesnym, można powiedzieć, formacie StructuredContent, to dla klientów i tak często musimy zwracać tą wersję tekstową w formie content"* (`184-186`). Both verified. A server returning byte-identical query results with no annotations and no text fallback passes `[#729]` and is wrong. · **The annotation half is not cosmetic here.** FPG-1's queries are read-only by construction, and `readOnlyHint` is the declaration that makes that fact reachable by the model rather than inferable from the organ's name -- the same asymmetry `[#729]` exists to remove, one layer in. · **This row is also the repair of an interpretive weakness in this lane's own matrix, stated rather than hidden.** 56 of M04's 82 verified items resolve to `[#729]` by ENTAILMENT -- `[#729]` commits to a conformant server, and those items are what conformance means -- while `[#729]` names none of them. A conformance criterion is what converts that entailment from a reading into something checkable, which is why the finding is filed instead of left as a caveat. · Done when: `[#729]`'s acceptance includes a protocol-conformance leg distinct from its output-equality leg -- the spec version the server targets is named, and conformance is demonstrated against it by an external client or a published conformance suite rather than by our own test alone; at minimum every exposed tool carries the annotations its behaviour warrants and returns the text fallback beside any structured payload · refs `AJ_M04_transkrypcje.md:159-162, 184-186` (the two items, quoted above), `docs/audits/2026-09-15-technical-lane-z-10-aj-m04-evidence/LOCATOR-VERIFICATION.md` (items 07, 08 -- verified), `docs/audits/2026-09-15-technical-lane-z-10-aj-m04-first-pass-packet.md` §2.2 and §2.5 (the 56 entailed items and the caveat this row discharges), `[#729]` (the row this one adds a leg to), `[#770]` (which spec version it would target, and how we would learn it moved) · kill-candidates: none -- `[#729]` is the row this one STRENGTHENS and closing it as written is exactly the outcome this row exists to prevent, so folding them would erase the distinction between "the answers match" and "the server is conformant"; `[#770]` supplies the version this criterion is stated against and does not itself test any server · source: batch Z lane z-10, AJ M04 first pass, `[#784]`
