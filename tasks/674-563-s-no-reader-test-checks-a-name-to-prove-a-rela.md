- [#674] [P2][M] **`[#563]`'s no-reader test checks a NAME to prove a RELATIONSHIP; it must assert the absence of a `reads` edge** - **TWO LIVE MECHANISMS COLLIDE BY CONSTRUCTION, and the operator ruled the test is the one that is wrong** (2026-09-09). V-9's `graph-orphan-census` (`[#664]`, merged `fc44afda`) FAILs on any script with no inbound `triggers` edge unless that script carries a **disposition**, and the disposition table is a dict whose **key is the script path**. `[#563]`'s invariant `tests/test_export_backlog_view.py::test_no_gate_hook_or_script_reads_the_export` proves nothing reads the export by **grepping the corpus for the substring `export_backlog_view`** (`_EXPORT_TOKENS`). So `scripts/graph_queries.py` **cannot name** `scripts/export_backlog_view.py` without tripping the test, and the census **requires** that it name it. The single offender the test reports is a disposition KEY - V-9 naming the file precisely to record that it is an orphan **BY DESIGN**, citing that very test as the reason it must stay unwired. **A key in a disposition dict is not a `reads` edge.** **THE CLASS IS THE POINT:** the operator counted six instances in two days of a check that reads a NAME to assert a RELATIONSHIP - `asserted_by` naming a non-reading organ, the v1.5.0 drift probe matching the literal `--report`, P11's presence-only check, and this. The test's own docstring already states the limit it hit ("this greps for the export's OWN names"), so the gap was declared before it bit. **This is the spine's first useful act: it settles a conflict a grep could not express**, and it is checkable only because FPG-1 is now armed. · Done when: `test_no_gate_hook_or_script_reads_the_export` asserts the ABSENCE of a `reads` edge into the export artifact, computed from the FPG-1 graph, instead of grepping `_EXPORT_TOKENS` across the corpus; `scripts/graph_queries.py`'s disposition for `export_backlog_view.py` no longer trips it; a RED-first witness per ADR-108 section B proves the corrected test STILL FAILS when a genuine reader of the export is introduced, so the fix does not buy a green by weakening the assertion; and `[#563]`'s three binding conditions are unchanged - governance still stays bespoke, this row changes only how that is proven · refs `tests/test_export_backlog_view.py` (`test_no_gate_hook_or_script_reads_the_export`, `_EXPORT_TOKENS`), `scripts/graph_queries.py` (`ORPHAN_DISPOSITIONS`), `[#563]` (CLOSED - this is the defect its landing left, not a re-open), `[#664]`, ADR-118, ADR-111, `docs/audits/2026-09-09-technical-batch-v-close-packet.md` (section 4) · kill-candidates: none - `[#563]` is closed and this row does not re-open it; no open row owns the export invariant or the graph's disposition table · source: operator ruling 2026-09-09, `DECLARE-BATCH-V-CLOSE-2026-09-09` section 2, filed by the batch V integrator at seat close
