- [#772] [P1][M] **Every dispatched lane inherits the whole secret store -- there is no introspect-and-exchange step and no row about it** -- AJ M04 L07's whole subject is that forwarding the caller's credential onward is the wrong design: *"przekazywanie tokena z MCP bezpośrednio do serwera nie jest najlepszym pomysłem"* (`AJ_M04_transkrypcje.md:1156-1157`), and the mechanism it prescribes instead is introspect the incoming token, EXCHANGE it for a backend-specific one, and pass the exchanged token -- never the original. L02 states the same boundary from the host side, as an obligation on the host rather than a courtesy: *"MCP Host ma tak na to obowiązek filtrować te prośby o Sampling, żeby serwer nie próbował na przykład wyłudzać jakichś poufnych danych z historii czatu"* (`343-345`). Both verified. · **The local analogue is direct and currently unmitigated.** Provider keys live in one `.env` loaded by the PowerShell profile, so every process started from that shell -- every dispatched lane, every `agy`, `codex`, `cursor-agent` and `copilot` invocation a lane makes, every subprocess those spawn -- receives the WHOLE store in its environment. A lane that needs one provider's key is handed all of them, which is the forwarding M04 refuses, one substrate down. · **The blast radius is not hypothetical for this repo's own routing.** `[#722]` routes read-only work to `agy` as a reader, and `[#753]` trials supervised non-Claude producers; every such invocation is a third-party binary inheriting credentials it has no reason to hold. `[#729]` will add an MCP server reachable by those same providers. · **A sweep found nothing to fold this into.** `BACKLOG.md` matched for `secret`, `credential`, `api key`, `token scope` and `.env` returns ZERO rows -- so this is not a known concern filed under another name; the subject is absent from the backlog entirely, which is the ADR-111 shape of a finding outside the funnel. · **What this row is NOT.** It does not allege a leak, does not propose a vault, and does not touch the operator's `keys` commands. It asks that a lane receive the credentials its contract declares it needs, which is the exchange step's minimal form. · Done when: a dispatched lane's credential exposure is DECLARED rather than inherited -- the contract or the dispatch verb names which provider credentials that lane requires, the launcher passes those and not the rest, and a lane requesting a credential its contract did not declare is refused with the credential named; proven by one lane dispatched with a narrowed environment doing its work unchanged · refs `AJ_M04_transkrypcje.md:343-345, 1156-1157` (the two items, quoted above), `docs/audits/2026-09-15-technical-lane-z-10-aj-m04-evidence/LOCATOR-VERIFICATION.md` (items 20, 75 -- verified), `docs/audits/2026-09-15-technical-lane-z-10-aj-m04-first-pass-packet.md` §2.5 (items 76-82, the exchange mechanism, owned by `[#729]` as server-side detail), `[#722]` (agy as reader -- an inheriting invocation), `[#753]` (non-Claude producers -- more of them), `[#729]` (adds a server those providers reach) · kill-candidates: none -- no open row names credentials, secrets or token scope at all (measured by sweep, above); `[#722]` and `[#753]` are CONSUMERS of the exposure and would each close having widened it rather than bounded it · source: batch Z lane z-10, AJ M04 first pass, `[#784]`
