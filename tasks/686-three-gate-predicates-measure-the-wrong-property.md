- [#686] [P2][M] **Three handoff-gate predicates measure the wrong property — carrier existence, file bytes, and an over-globbed population** - Row 11 of `to-cc/DECLARE-REVIEW-CONSUMPTION-2026-09-10.md`, filed FILE, `[#664]` family. All three were found by running the gate in the 2026-09-10 window rather than by reading it, and each is a gate that passes or fails on a proxy for the property it names. · **(a) P11 checks EXISTENCE where it means REFERENCE.** `protocols/HANDOFF_PROCESS.md:376` requires `carried-by:` to name "the repo home that will hold it" and the value to "resolve on `main`". The live check resolves the PATH (`git cat-file -e main:<path>`) — so a decision file passes while the home it names references the decision nowhere. Intake #90 is the witness: it is a valid carrier for `DECLARE-DISPATCH-SEAM-AND-ENTERPRISE-2026-09-08` and carried 1 of that DECLARE's 7 rulings, partially, until A4-4 appended them. A carrier must resolve only if the named home actually references the decision. · **(b) P8b measures BYTES where it means LIVENESS.** The rule at `protocols/OPERATOR-INTERFACE.md:162` is a proxy for "this is a seat's current working surface, not history". A closed seat's file passes it by being small: `STATUS-INTEGRATOR-N3.md` sits at 4,992 B against the 5,000 B bar — an 8-byte margin — while its own first heading says `QUEUE DRAINED` and its batches are closed. The predicate should read the seat's liveness; bytes are what it reads instead. · **(c) P11's POPULATION over-globs.** `:376` scopes the check to "every decision file **the window** puts on the transport"; the hand recipe globs all of `to-cc/DECLARE-*` / `AMEND-*` / `BATCH-*`, so a concurrent workstream's files enter the count and FAIL the window's gate. Three such files appeared during the 2026-09-10 window alone (`DECLARE-cv-f2-2026-09-10.md`, `AMEND-GITHUB-REVIEW-001.md`, `AMEND-GITHUB-TIDY-001.md`), and the window was blocked on files it does not own. The population is the window's files by MANIFEST, not by glob. · **Why one row and not three:** all three are the same class — a gate whose predicate is a cheap proxy for its stated property — and all three live in the same two documents, so splitting them multiplies the coupled edit without separating any decision.
