- [#803] [P1][M] **A substrate request is availability-gated and silently downgraded while reporting success — the dispatcher must verify the substrate it RECEIVED against the one it ORDERED, before briefing the lane** — **MEASURED 2026-09-15, batch AA, by the dispatcher seat against itself.** Six lanes were dispatched with remote/cloud isolation. Every one returned **"Async agent launched successfully"**. Every one ran in a **LOCAL worktree** at `.claude/worktrees/agent-<id>` on the operator's workstation. Remote availability is **gated**; on refusal the request falls back to local worktree isolation and **the launch receipt says nothing about the downgrade**. **Eight agents ran on the operator's box while the seat that launched them believed they were remote** — and that is the best available explanation for the day's memory pressure. · **THIS IS THE RECOVERY-CONTAINER CLASS, ONE LAYER OUT.** `DECLARE-POST-Z-PLAN-2026-09-15.md` §1 records the container case: `postCreateCommand` failed, Codespaces substituted a bare recovery container, the platform said Available throughout, and gates there were **VACUOUS, not absent** — the dangerous shape, because absence announces itself and vacuity does not. The substitution here is the same predicate at the *dispatch* layer instead of the *container* layer: a request for substrate X silently served by substrate Y, with success reported. It is the **seventh** sighting of the shape the batch-Z close packet enumerates six times, and — as with all six — **it was not found by the organ that owned it.** It was found downstream by `git worktree list`. · **THE FIX IS A REFUSAL AT DISPATCH, AND IT REUSES aa-1's PREDICATE — DO NOT WRITE A SECOND ONE.** Lane aa-1 built exactly this check for the container marker (`scripts/substrate_provenance.py`, branch `worktree-lane-aa-1-substrate-provenance`, `f0681233`): a substrate is the **pairing of a host and the checkout it serves**, `substrate_id = sha256(CODESPACE_NAME + host + machine/boot token + real checkout path)`, written into the marker and **re-checked on read** so a copied, inherited or neighbouring marker is refused even at the correct path. **Seven concurrent lane worktrees on one box are therefore seven substrates** — precisely the discrimination this defect needs. The dispatcher calls that same predicate on the substrate it RECEIVED and compares it against the one the contract ORDERED. **Mismatch is a REFUSAL, before the lane is briefed** — because a brief written for the wrong substrate is worse than no brief: today four lanes were told "no pre-commit hooks are armed here" on a box where hooks ARE armed, and two read-only lanes were told they could not see unpushed refs when they could. · **THE PLACEMENT IS THE WHOLE MECHANISM, exactly as with the lane-ceiling.** Verified AFTER briefing, the check is decorative: the brief is already wrong, the box is already loaded, and the only remaining option is a teardown. Verified BEFORE briefing, it is free. · **THREE MORE SURFACES LIED THE SAME WAY ON THE SAME DAY, so the row is about a class rather than one call.** (1) `claude stop <id>` reported **"stopped ae6a2fc4"** and the session kept working for another hour. (2) A `taskkill /T` tree kill of that session walked **eleven levels** and reported `ERROR: The process with PID 38500 ... could not be terminated. Reason: Access is denied.` — a descendant surviving a tree teardown, which is the upstream reparenting defect reproduced locally. (3) `claude agents --json` continued to report that session **`busy`** after its PID was confirmed dead. **A control-plane surface's self-report is not evidence of the state it reports.** · Done when: the dispatcher verifies the RECEIVED substrate against the ORDERED substrate using `substrate_provenance`'s existing predicate — not a second implementation — and REFUSES on mismatch before any brief is written; the refusal names both substrates; a test witnesses a downgraded request being refused, having first witnessed it silently accepted; and the receipt records both ordered and received substrate so a batch can be audited after the fact · refs `scripts/substrate_provenance.py` and `scripts/substrate_heartbeat.py` (aa-1, `f0681233` — the predicate to reuse), `DECLARE-POST-Z-PLAN-2026-09-15.md` §1, `docs/audits/2026-09-15-technical-batch-z-close-packet.md` (the six prior sightings), `[#789]`, `[#748]`, `[#752]` · kill-candidates: none — `[#748]` owns a worktree that REDIRECTS to the primary (a different failure: isolation lost, not substrate substituted); `[#752]` owns a contract's declared model reaching no flag, which is the same *class* on the model axis and should be read beside this row · source: dispatcher seat self-audit, batch AA, 2026-09-15
