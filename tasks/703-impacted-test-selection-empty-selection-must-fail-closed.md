Carried at `docs/intake/2026-09-11-tech-batch-x-roster.md` (intake 93). · **AX1-3 makes it a PRECONDITION, not a follow-up**, and states the requirement in its own words: "W-7's owed MED is fixed -- an empty selection FAILS closed (runs everything), never passes as 'nothing impacted'." It is a precondition on the merge-cost lane because that lane's entire value rests on the selector being trustworthy: a selector that can silently select nothing does not make merges cheap, it makes them unverified. · **The two readings of an empty selection are indistinguishable from inside.** Empty means either "this diff genuinely impacts no test" or "the selector failed to resolve the diff" -- a renamed module, an unparsed path, an import graph that came back empty. The first is rare; the second is a normal consequence of any refactor that moves files. Treating them the same way defaults the failure mode to the dangerous one: a green run that tested nothing, which reads in the receipt exactly like a green run that tested everything relevant. · **Fail-closed costs a full suite; fail-open costs a wrong merge**, and the asymmetry is the whole argument. This is also the class this repo has already been bitten by from the other direction -- a fail-safe in the caller is a latent trap -- so the hardening belongs in the selector, not in each of its callers. · Done when: an empty selection FAILS CLOSED and runs everything, never passing as "nothing impacted"; and one test FAILS when the empty case is allowed to pass -- a RED-first witness per ADR-108 section B · **Done-when carried from `to-cc/AMEND-BATCH-X-ROSTER-001.md` AX1-3's precondition clause**, which states this requirement directly; the roster's section-4 list carries no Done-when column of its own · refs `docs/intake/2026-09-11-tech-batch-x-roster.md` (intake 93, section 4 and Part 5's AX1-3 entry), `to-cc/AMEND-BATCH-X-ROSTER-001.md` AX1-3 (the precondition), `to-cc/AMEND-BATCH-W-005.md` AW5-5 (filed at batch close with a non-colliding id), `scripts/impacted_tests.py`, `tests/test_impacted_tests.py`, `[#278]` (the test-suite-hygiene epic W-7 un-deferred, this row's parent), `[#528]` (lane latency -- the measurement the selector serves) · kill-candidates: none -- `[#278]`'s Done-when asks that impacted-test selection be "live in the verify cadence with a test", which a selector that silently selects nothing satisfies; the empty-case semantics are not reachable from it, and AW5-5 directs this to a row of its own · source: `to-cc/DECLARE-BATCH-X-ROSTER-2026-09-11.md` section 4 with `to-cc/AMEND-BATCH-X-ROSTER-001.md` AX1-3 and `to-cc/AMEND-BATCH-W-005.md` AW5-5, filed 2026-09-11 by lane `lane-x-000-batch-x-roster-lands`
