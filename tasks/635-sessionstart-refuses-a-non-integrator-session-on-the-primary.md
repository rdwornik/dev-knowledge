- [#635] [P2][S] **SessionStart refuses a non-integrator session on the primary checkout — the TOCTOU `block-commit-on-main` cannot close** — **Filed 2026-09-05 by integrator ruling; candidate, filed not built.** WITNESSED, not theorised: a commit landed on `main` while `block-commit-on-main` reported **Passed**, and the gate was not defective — it was probed live in the same session and refuses correctly. A time-of-check/time-of-use race: pre-commit ran the hooks with `HEAD` on a feature branch, a concurrent session ran `git checkout main` during the ~20s hook run, and git re-resolved `HEAD` at ref-write time. **A client-side pre-commit hook cannot hold an atomic claim on `HEAD`**, so no hardening inside that hook closes this — check and use are separated by the hook's own runtime, and the window is as long as the mesh is slow. The remedy is at a different layer: make the primary checkout single-occupancy so the concurrent `checkout` never happens. `SessionStart` is the natural home because it fires before a session can act, and the social version already worked in the same window — an integrator-only notice to six live seats produced clean isolation. This makes that convention a mechanism. **Honest limit, stated up front:** a `SessionStart` refusal is advisory in the same sense the notice was, and a session can still `cd` into the primary mid-run — a narrowing, not a proof. · Done when: a `SessionStart` hook detects the session's cwd is the primary checkout (not a `.claude/worktrees/*` path) AND another live session already holds it, and refuses with a message naming the worktree route; a seeded test simulates two sessions on the primary and asserts the second is refused; and the integrator seat has a declared way to identify itself rather than being refused by its own guard · refs `scripts/block_commit_on_main.py` (the stated detached-HEAD hole is the same defect class), JOURNAL 2026-09-05 (a), `[#527]` · kill-candidates: none — a newly witnessed race with no existing row covering it; `[#527]` stays open as the commit-time half this cannot replace · source: integrator ruling 2026-09-05, merge-queue item 5
