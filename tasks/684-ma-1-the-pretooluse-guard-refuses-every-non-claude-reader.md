The result is not a degraded read but a total one: the reader is blocked before it does anything. · **Why this is the expensive half of REVIEW's R1-2.** The night mission's cursor-agent leg (`REVIEW.md:462`) names it as the first of two questions and the more expensive one — *"Do we fix `.claude/settings.json:21` before any non-Claude reader is ordered again?"* — because every future multi-reader leg pays this cost until it is fixed, and the failure looks like the reader being broken rather than the harness refusing it. · **Two edits, both narrow:** the hook resolves its own repo root rather than trusting an inherited variable (fallback to the repo root it can compute), and the matcher is narrowed so the guard applies to the tool classes it was written for instead of every call. Neither weakens what the guard actually guards — memory of the class is that a guard which refuses tools is landed unarmed and armed as a separate act.
