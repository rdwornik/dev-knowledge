- [#839] [P1][M] **FPG-1 represents a missing target as an explicit dangling edge — the graph stops dropping the defect class it exists to catch** — operator ruling 2026-09-17 on lane `ab-664-spine-witnessed`'s class (c) fork: YES, the graph must REPRESENT a reference to something that no longer exists, not drop it. Today `PurposeGraph.add_edge` in `scripts/file_purpose_graph.py` drops a dangling or self edge "by construction" — so a reference to a retired target is silent inside the one structure every organ is meant to read, which is the same silent-success shape its gates exist to catch. The class keeps costing: a retired module still called by `provision.sh`, `INSTALL.md` left at a consumer root, a deleted script still named in a Done-when. Measured cost of the current invariant: 8 of the 17 private edge computations re-measured by that lane refuse on exactly this — a probe naming a gone file, an `@include` resolving to nothing, a kill-candidate that closed — and cannot migrate onto FPG-1 while the graph drops them (`docs/audits/2026-09-17-census-lane-ab-664-edge-class-remeasure.md` §3, blocker `D`). **A design change to FPG-1, filed as its own row by the same ruling rather than absorbed into `[#664]`.** It amends ADR-118's "a dangling edge is dropped, never invented" reading, so the amendment rides in this row's landing, not in passing. Self edges stay dropped; only the unresolved-target case changes. **Anti-patterns:** no invented node that reads as a live file (a dangling target must be distinguishable from a present one in every query, or `orphan_census` and `process_list` start trusting ghosts); no silent resolution by basename. · Done when: a reference whose target does not exist is persisted in the FPG-1 store as an explicitly DANGLING edge (the target marked unresolved, the consumer and the reference's source input retained), enumerable by a query over the store; every existing query that must not treat a ghost as present (`orphan_census`, `task_coverage`, `process_list`) is proven unchanged on the live tree by a before/after diff; RED-first witnesses plant each of the three named instances' shapes (a script call-site to a deleted module, a doc naming a deleted script, a Done-when naming a deleted path) and see a dangling edge where today there is none; and ADR-118 carries the in-file amendment recording the changed invariant · refs docs/decisions/ADR-118-one-graph-organs-are-views.md, scripts/file_purpose_graph.py, scripts/graph_store.py, scripts/graph_queries.py, docs/audits/2026-09-17-census-lane-ab-664-edge-class-remeasure.md, docs/audits/2026-09-16-technical-lane-ab-664-spine-witnessed.md, [#664] · kill-candidates: none -- newly filed by operator ruling · source: operator ruling 2026-09-17 on lane ab-664-spine-witnessed class (c), filed from the lane's id block 839-842
