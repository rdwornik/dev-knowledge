- [#805] [P1][M] **An integrator finishes a batch unattended on recorded defaults** - Operator ruling 2026-09-16. **A batch that can only close while a human is awake is not an unattended batch.** Batch AA's integration stopped and waited for the operator on three questions, and every one had a rule-shaped answer: two lanes (aa-13, aa-14) touching one file; a silent-rule baseline raise (447 -> 452) from a lane that had been ASKED to add register entries; and dead zero-commit worktree husks holding the 12-worktree ceiling. **MEASURED from the seat's own transcript**: the four merges (codespaces, aa-4, aa-5, aa-2) each took 5.8-22.6 min of wall time, of which the `git merge` itself was 0.7-1.1 min and pre-commit hooks were 1.3-6.3 min; the seat then sat 10.6 h between its last tool call (2026-09-15 21:43) and the operator's rulings (2026-09-16 08:17). The integrator was not slow; it was waiting. · **THE DEFAULTS, each applied AND RECORDED (in the merge commit body and the receipt), never silent:** (a) **file conflict between two lanes** -> the lane whose contract is LIVE wins; a withdrawn or superseded contract's lane loses, and its commits are reviewed for anything the winner lacks, folded or dropped with a stated reason (the 2026-09-16 aa-13/aa-14 disposition is the worked example); (b) **an empty worktree with zero commits and a clean tree** -> torn down without asking, both branches, per the WORKTREE TEARDOWN IS TWO BRANCHES rule; (c) **a ratchet baseline raise** -> passes when the lane's frozen contract asked it to add entries of that class, with the arithmetic (before, added, removed, after) recorded, and escalates otherwise. **MEASURED 2026-09-16: TODAY THIS DEFAULT CANNOT BE APPLIED EVEN WITH THE OPERATOR'S RULING IN HAND.** The operator approved silent-rule 447 -> 452 for aa-14; the integrator measured 452 exactly and `silent_rule_ratchet` refused the commit anyway, because `silent_rule_detector.validate_transition` rejects every raise and the check has no ruling input at all (the gap recorded 2026-09-06 as `commensurable-ratchet-raise-has-no-landing-path`). The raise was abandoned for a meaning-preserving drain of five descriptive tokens. An approved ruling that no mechanism can land is a stop dressed as a pass. · **ESCALATION IS ADR-108 §A, NOT CAUTION.** The integrator escalates only what §A makes FUNCTIONAL -- what the system should do, priorities between outcomes. A technical fork is decided, recorded and marked revertable (§A item 2). A default that fires wrongly is reverted; a default that never fires costs a night. · Done when: (1) `/lane-integrate` carries the three defaults as ordered steps with the record each must write, and states that everything else not functional under ADR-108 §A is decided by the seat; (2) each default has a mechanical detector the integrator runs (live-vs-withdrawn contract lookup; zero-commit + clean worktree probe; contract-asked-for-entries check against the ratchet delta) so the default is applied by evidence, not by the seat's reading; (3) a dry-run over batch AA's recorded state reaches merge-complete with ZERO operator stops and a record for each of the three; (3b) the silent-rule ratchet accepts a raise that carries a recorded authorisation (the lane contract's clause or a ruling id) and still refuses an unauthorised one, with a RED-first witness for each; (4) the refuse-to-finish checklist gains "every default applied is recorded", so an unrecorded default blocks close exactly as an unreceipted merge does · refs `.claude/commands/lane-integrate.md`, ADR-108 §A, `[#793]` (the aa-13/aa-14 file conflict), `[#804]` (the missing manifest that made the conflicts), `ecosystem/silent-rule-baseline.yaml`, `.claude/rules/git-discipline.md` (WORKTREE TEARDOWN IS TWO BRANCHES), JOURNAL 2026-09-16 · kill-candidates: none -- `[#793]` owns the withdrawn-lane MECHANISM (tear down at withdrawal) and stays open because a default applied at integration is the fallback for exactly the case that mechanism fails to prevent; `[#804]` prevents collisions, this row resolves the ones that still happen · source: operator ruling 2026-09-16, with the integrator's per-merge wall-time split
