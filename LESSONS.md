### 2026-07-01 | ADR-92 deploy run #1 (Windows git I/O as a from-the-start invariant) | A tool that deploys from a Windows box to git must treat **binary + UTF-8 + LF as a TESTED INVARIANT from the first commit**, not a reactive patch — and must fix the CLASS, not the instance.
