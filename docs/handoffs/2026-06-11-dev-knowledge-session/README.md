This is **not** a v4 eight-file teaching bundle, by design. v5 emits the **residual** —
what the repo does not already encode — plus a thin boot pointer and a teeth-bearing
probe manifest. Four lean files:

| File | What it is |
|---|---|
| `HANDOFF_BOOT.md` | **Thin boot pointer** — what to paste into a fresh browser chat (points at `protocols/HANDOFF_BOOT.md`; does not copy it). |
| `RESIDUAL.md` | The **residual** — drift-flags (headline), un-committed session reasoning, pointers, lean task-state. |
| `PROBES.md` | The **probe manifest** — 6 teeth-y forced-read probes: question + source-locator + verification command, **no answers**. |
| `README.md` | This index. |

## Use

1. **Boot the browser.** Open a fresh Claude.ai chat; paste `protocols/HANDOFF_BOOT.md`
   (per `HANDOFF_BOOT.md` here). The browser replies with its on-load acknowledgment.
2. **Hand over the residual.** Give the browser `RESIDUAL.md` — drift-flags first.
3. **Run the comprehension gate.** Work `PROBES.md`. The browser has no file access, so
   for every probe it must answer **"run `<command>`"** — that surfaces the off-bundle
   dependency rather than hiding it. **CC** runs each command against **live state at
   check-time**, re-derives ground truth, and emits PASS/FAIL. **Any FAIL blocks
   onboarding** (degrade loudly — never synthesize a pass).

## Dogfood verdict (#149 gate 3)

This run was checked against §5's empirical-teeth gate: each of the 6 probes was
attempted **from a compaction summary / this artifact alone**, without opening the live
primary source. **All 6 fail to be answered that way** — every probe's exact answer is
deliberately kept *out* of the residual (only question + locator + command ship), so the
only path to an answer is opening the live file/state. The teeth bite. See
`RESIDUAL.md` § "Why the probes have teeth" for the design rule.
