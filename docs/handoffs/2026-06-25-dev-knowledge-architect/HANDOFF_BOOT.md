## What the operator does (paste-pointer)

1. Open a fresh Claude.ai chat.
2. Paste **`PASTE_THIS.md`** (in this bundle directory) — the browser role file + residual + probes, assembled in order by `scripts/assemble_paste.py`. One paste; never hand-feed individual files to the file-less browser.
3. The browser replies with its on-load acknowledgment line (it names the Layer-1 actor); a partial or missing paste is then visible.
4. **Architect mode** — the browser uses the **generative / decompositional** posture (`protocols/HANDOFF_BOOT.md` §"Architect mode"): orient first, ask the operator for off-repo context, drive decomposition, hold the whole-system view, surface design tensions — **not** the reactive-filter default.
5. **Orient before any mechanism** — hand the browser `PROBES.md` **P1** (orientation) first; it replies `run <command>`, CC reads live `VISION.md` / `ARCHITECTURE.md` Ch1 and substring-checks. The architect may not begin design until it holds both orienting lines. (P1's grep is a *tool* that confirms the frame — the **backlog navigates**, v5.3 §13c.)
6. **Then the operator-context beat (§13d).** The supplement is **FILLED** (its ANSWERS are in the paste), so the beat **narrows** — do **not** re-ask intent/priorities/findings whole; ask only *"anything changed since the supplement was written?"* (the Q1–Q6 + A/B + A–F answers already carry this window's off-repo "why").
