## Use

1. **Boot the browser.** Open a fresh Claude.ai chat; paste `protocols/HANDOFF_BOOT.md`
   (per `HANDOFF_BOOT.md` here). The browser replies with its on-load acknowledgment. This
   handoff is **execution mode** → the browser uses the reactive-filter role (not the
   architect generative posture, which also lives in that file).
2. **Hand over the residual.** Give the browser `RESIDUAL.md` — **drift-flags first**.
3. **Run the comprehension gate.** Work `PROBES.md`. The browser has no file access, so for
   every probe it must answer **"run `<command>`"** — that surfaces the off-bundle dependency
   rather than hiding it. **CC** runs each command against **live state at check-time**,
   re-derives ground truth, and emits PASS/FAIL. **Any FAIL blocks onboarding** (degrade
   loudly — never synthesize a pass).

## Teeth note (v5 §5)

Every probe's exact answer — the check count, the HEAD sha, the drifted `#id`, the freshness
dates, the collected-count integers — is deliberately kept **out of this whole bundle**. Only
question + locator + command ship, so the only path to an answer is opening the live
file/state. A summary can't bluff them; that is the point. See `RESIDUAL.md` §4.
