## Use

1. **Boot the browser.** Open a fresh Claude.ai chat; paste the full contents of
   `protocols/HANDOFF_BOOT.md` (per `HANDOFF_BOOT.md` here). The browser replies with its
   on-load acknowledgment. Because this handoff **names architect mode**, it adopts the
   generative posture — orient first, **ask the operator for off-repo context**, drive
   decomposition, hold the whole-system view, surface design tensions — **not** the
   reactive-filter default.
2. **Orient first — the architect's first move (v5 §13c).** Before anything else, run the
   **orientation probe** in `PROBES.md` (P1): the browser, having no files, replies
   **"run `<command>`"**; **CC** reads the **live** `VISION.md` / `ARCHITECTURE.md` Ch1 and
   substring-checks the quote. The two orienting lines enter the session only by CC reading them
   live — never copied into this bundle, never paraphrasable from a summary.
3. **Operator-context beat (v5 §13d).** After orienting, before design, the browser asks the
   operator **one** targeted question for **off-repo** context — intent, priorities for this
   planning session, findings not in the repo, changed decisions. CC's handoff is repo-derived
   and cannot carry operator intent; the beat is the only channel for it. Off-repo only (not a
   re-narration of `RESIDUAL.md`), architect mode only.
4. **Hand over the residual.** Give the browser `RESIDUAL.md` — **drift-flags first**, then the
   open architecture questions + the task-graph.
5. **Run the comprehension gate.** Work the rest of `PROBES.md`. The browser has no file access,
   so for every probe it must answer **"run `<command>`"**. **CC** runs each command against
   **live state at check-time**, re-derives ground truth, and emits PASS/FAIL. **Any FAIL blocks
   onboarding** (degrade loudly — never synthesize a pass).

## Teeth note (v5 §5)

Every probe's exact answer — the orienting lines, the check count, the HEAD sha, the drifted
`#id`, the `no_ff_merges` sha — is deliberately kept **out of this whole bundle**. Only question
+ locator + command ship, so the only path to an answer is opening the live file/state. A summary
can't bluff them; that is the point. See `RESIDUAL.md` §1 + `PROBES.md`.
