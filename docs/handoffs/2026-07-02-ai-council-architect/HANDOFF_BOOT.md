## What the operator does (paste-pointer)

1. Open a fresh Claude.ai chat.
2. Paste **`PASTE_THIS.md`** (in this bundle directory) — the browser role file + residual + probes,
   assembled in order by `scripts/assemble_paste.py`. One paste; never hand-feed individual files to
   the file-less browser. (The empty supplement is **not** folded in — cold handoff.)
3. The browser replies with its on-load acknowledgment line (it names the Layer-1 actor); a partial or
   missing paste is then visible.
4. **Architect mode** — the browser uses the **generative / decompositional** posture
   (`protocols/HANDOFF_BOOT.md` §"Architect mode"): orient first, ask the operator for off-repo context,
   drive decomposition, hold the whole-system view, surface design tensions — **not** the reactive-filter default.
5. **Orient before any mechanism** — hand the browser `PROBES.md` **P1** (orientation) first; it replies
   `run <command>`, CC reads **ai-council's** live `VISION.md` / `ARCHITECTURE.md` Ch1 and substring-checks.
   The architect may not begin design until it holds both orienting lines. (P1's grep is a *tool* that
   confirms the frame — the **backlog navigates**, v5.3 §13c.)
6. **Then the operator-context beat (§13d) fires FULL.** The supplement is **EMPTY** (cold cross-repo
   handoff), so the browser asks the full off-repo question — intent, priorities, off-repo decisions/findings
   for this ai-council planning session — **not** a narrowed "anything changed since?" check.
7. Hand `RESIDUAL.md` — **drift-flags first** (the headline: the JOURNAL/LESSONS narrative lags git by
   ~4 weeks; methodology adoption is DONE, not a gap) — then the **next-frontier decisions** (§4, led by
   the **G5 baseline experiment** + the sequencing call: baseline-first vs. dogfood-Council-debate) + the
   **shipped-this-window** map (§2) + run the rest of `PROBES.md` (P2–P7) **from the ai-council checkout**.
   Any probe FAIL blocks onboarding (the escalation ladder).

## Why a pointer, not a copy

The methodology, the browser role, and the operator runbook all live in the hub and are referenced by
**pointer**; hub CC serves any part the file-less browser needs just-in-time, and the incoming session's
CC re-derives ai-council state live. `PASTE_THIS.md` is the assembled boot source (generated by
`scripts/assemble_paste.py`, never hand-edited); `docs/handoffs/README.md` is the operator runbook. If a
pointer and its source disagree, the source wins — fix the pointer or regenerate `PASTE_THIS.md`.
