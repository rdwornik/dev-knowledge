# Tech radar

Quarterly inventory of tools, models, and patterns Rob has evaluated for LLM-augmented dev work. Per PLAYBOOK Section 6 "Continuous Improvement."

## Files

- `YYYY-Q.md` — quarterly snapshot (current state of adopted / rejected / deferred / discovered)
- `YYYY-MM-DD-{tool}.md` — per-tool deep-dives when warranted (e.g. Spec Kit evaluation)

## Distinct from `docs/research/`

- `docs/research/` — Council research-mode debate outputs (point-in-time deep dives)
- `docs/tech-radar/` — quarterly inventory snapshots (state across all evaluated items)

A tool may appear in both: research/ has the debate transcript; tech-radar/ has the decision record + subsequent quarterly review status.

## Reading current state

Open the most recent `YYYY-Q.md` file. Sections:
- **Adopted this quarter** — net new
- **Rejected this quarter** — net new with rationale
- **Deferred this quarter** — net new with reopen trigger
- **Adopted (active)** — running inventory, value check
- **Deferred (waiting)** — running inventory, trigger watch
- **Discovered, not yet triaged** — backlog
